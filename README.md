# DevOps CI/CD Automation Platform

An end-to-end DevOps portfolio project demonstrating
automated software testing, containerisation,
security scanning, deployment, and monitoring.

## Technology Stack

- Git and GitHub
- Python and Flask
- Pytest
- Jenkins
- Docker
- SonarQube
- Trivy
- Kubernetes and Helm
- Terraform
- Prometheus and Grafana

## Project Structure

- app/ - Application source code
- tests/ - Automated tests
- docs/ - Technical documentation

## Project Status

Under active development.
